# FreshMart Grocery Store
A beginner-friendly grocery store website built to practise frontend development.
## Technologies Used
- HTML
- CSS
- JavaScript
## Features
- Displays grocery products and prices
- Searches products by name
- Includes a basic cart counter
- Responsive product layout using CSS Grid
- Home/reset button
## How to Run
1. Download the project files.
2. Open `index.html` in a web browser.
3. Try the product search and Add to Cart buttons.
## Current Limitations
The cart counter counts button clicks. It does not yet track individual products or calculate the total price. The project does not include a backend or database.
## Purpose
This is a learning project created to practise HTML, CSS, and JavaScript.
